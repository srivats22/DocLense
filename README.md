# DocLense

View Project Dependency documentation directly in your editor.

## Features

DocLense is a VS Code extension that 
1. Automatically scans your project's dependencies
2. Displays the dependencies in the sidebar
3. Clicking on the dependency opens the dependency's documentation site either inside the editor or launches your default browser

## Note

DocLense currently supports only npm based projects. Other languages and frameworks will be supported in future releases.
